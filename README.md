# william-ricchiuti/homebrew-tap

Homebrew casks for William Ricchiuti's apps.

## Vault Wallpaper

Your Obsidian vault's link graph as a live macOS desktop wallpaper.

```bash
brew trust --cask william-ricchiuti/tap/vault-wallpaper
brew install --cask william-ricchiuti/tap/vault-wallpaper
```

Homebrew 7 and later only load casks from third-party taps you have trusted; the first line
trusts just this cask.

The cask is updated automatically by the
[vault-wallpaper](https://github.com/william-ricchiuti/vault-wallpaper) release workflow.
